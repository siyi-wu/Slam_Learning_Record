# ch4 学习脚手架：李群李代数与 Sophus

## 章节目标

1. 理解 SO(3)/SE(3) 与李代数的关系。
2. 掌握 `log` / `exp` / `hat` / `vee` 在代码中的对应。
3. 能用小扰动更新位姿并保持旋转合法性。

## 文件入口

- `code/ch4/useSophus.cpp`
- `code/ch4/example/trajectoryError.cpp`

## 学习检查点

1. 你能解释为什么位姿更新要在李代数空间进行。
2. 你能说清左乘更新和右乘更新的区别。
3. 你能使用轨迹误差程序评估两条轨迹的一致性。

## 建议实践

1. 在 `useSophus.cpp` 中修改更新量，观察变换矩阵变化趋势。
2. 在轨迹误差程序中输出每帧误差并绘制简单统计。

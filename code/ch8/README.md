# ch8 学习脚手架：光流法与直接法

## 章节目标

1. 理解光度一致性假设与直接法核心思想。
2. 掌握单层/多层金字塔光流实现细节。
3. 能分析直接法中的链式求导与雅可比构建。

## 文件入口

- `code/ch8/optical_flow.cpp`
- `code/ch8/direct_method.cpp`

## 学习检查点

1. 你能解释前向光流与逆向光流的计算差异。
2. 你能说明金字塔策略如何提升大位移场景鲁棒性。
3. 你能逐步对应 `J_img_pixel * J_pixel_xi` 的链式法则。

## 建议实践

1. 在 `optical_flow.cpp` 中输出每轮迭代误差，分析收敛性。
2. 在 `direct_method.cpp` 中修改 patch 大小并比较定位精度与速度。

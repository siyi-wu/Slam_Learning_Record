# ch6 学习脚手架：非线性优化基础（Gauss-Newton）

## 章节目标

1. 理解最小二乘问题、残差与雅可比。
2. 掌握 Gauss-Newton 法的迭代流程。
3. 能把公式映射到 `H`、`b`、`dx` 的代码实现。

## 文件入口

- `code/ch6/gaussNewton.cpp`

## 学习检查点

1. 你能解释 `H = J^T J` 与 `b = -J^T e` 的来源。
2. 你能分析 `cost` 增大时提前终止的必要性。
3. 你能调整初值并观察收敛速度变化。

## 建议实践

1. 为 `gaussNewton.cpp` 增加每轮参数误差日志。
2. 用数值差分验证手写雅可比的正确性。

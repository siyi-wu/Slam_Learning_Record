# code 目录学习路线（全书）

本目录用于承接你对《视觉SLAM十四讲》的本地学习代码。

## 当前结构

- `ch2` ~ `ch8`：你已完成/已有示例。
- `ch9` ~ `ch13`：已建立学习脚手架，可基于 `slambook2` 逐步新增和改写。

## 与 slambook2 的对应原则

1. 优先理解后重写，不直接无脑复制。
2. 每个新增示例在文件头注释说明：来源章节、改写点、测试命令。
3. 维持你自己的代码风格（命名、注释、目录组织）以便长期维护。

## 建议节奏

1. 第9章：先跑通 `bundle_adjustment_g2o.cpp`，再补 `ceres` 版本。
2. 第10章：先跑位姿图优化，再对比李代数版本差异。
3. 第11章：先完成回环检测流水线可视化，再做参数调优。
4. 第12章：从点云拼接开始，再做降采样与地图压缩。
5. 第13章：从模块阅读入手，逐个梳理前端/后端/地图模块职责。

# 视觉SLAM学习仪表盘项目规范（skill.md）

## 1. 项目定位
本项目用于构建一个本地可交互的「视觉SLAM学习仪表盘（Web）」，服务《视觉SLAM十四讲》全书学习。

核心目标：
- 建立“物理直觉 -> 数学推导 -> C++实现 -> 工程库调用”的闭环学习路径。
- 统一管理章节代码、理论文档、公式推导与源码映射。
- 支持长期增量扩展（双目、MVS、回环、VIO 等专题）。

---

## 2. 技术选型

### 2.1 主框架
采用 **VitePress**。

### 2.2 选型理由
- 原生支持 Markdown，适合知识型内容沉淀。
- 支持数学公式渲染、代码高亮、侧边栏导航与站内检索。
- 基于 Vite，启动快、构建快、迭代效率高。

---

## 3. 内容架构

### 3.1 C++过渡模块
- 面向 C 程序员的现代 C++迁移。
- 聚焦 SLAM 高频语法与工程实践。

### 3.2 核心库模块
- Eigen / Sophus / OpenCV / Ceres / g2o / PCL
- 统一模板：核心数据结构、适用范围、典型 API。

### 3.3 理论映射模块
- 刚体运动、李群李代数、非线性优化、对极几何。
- 统一模板：物理概念、LaTeX 公式、代码映射。

### 3.4 章节索引模块
- 全书第 1~14 章连续映射。
- 每章统一入口：`code/chX` 与 `code/chX/README.md`。

## 5. 文档规范（强制）

### 5.1 通用规范
- 语言：中文主述，关键术语保留英文。
- 结构：`问题背景 -> 核心概念 -> 数学表达 -> 代码映射 -> 小结`。
- 风格：专业、清晰、可执行。

### 5.2 公式规范
- 行内公式：`$...$`
- 块级公式：`$$...$$`
- 全站符号统一：`\mathbf{R}`、`\mathbf{t}`、`\mathbf{T}`、`\boldsymbol{\xi}`。

### 5.3 代码规范
- 优先现代 C++（C++11/14/17 常用特性）。
- 每段代码需说明：理论对应点、输入输出、关键语句注释。
- 代码块标注语言类型（`cpp` / `cmake` / `bash` 等）。

### 5.4 公式-代码映射规范
每个推导密集章节必须包含：
1. 目标函数或几何约束
2. 残差与雅可比推导
3. 对应代码位置（函数/类/关键语句）
4. 数值稳定性与工程近似说明

### 5.5 路径规范
- 所有路径使用仓库相对路径。
- 代码路径统一使用：`code/chX/...`
- 文档路径统一使用：`docs/...` 或 `slam_learning_dashboard/docs/...`

### 5.6 提交规范
- 维护 `.gitignore`，避免冗余文件入库。
- 排除依赖目录、构建产物、缓存文件与临时文件。

---

## 6. 执行规范

- 内容更新顺序：先更新 `code/chX` 与 `code/chX/README.md`，再更新 dashboard 对应章节。
- 导航一致性：新增内容必须同步更新章节映射与侧边栏。
- 风格一致性：目录、命名、文案、链接格式保持统一。

---

## 7. 验收标准

- 全书章节（1~14）在索引页连续可达。
- 每章具备代码入口与 README 脚手架入口。
- 文档支持公式渲染、代码高亮与有效跳转。
- 路径规范统一，仓库可清洁提交。

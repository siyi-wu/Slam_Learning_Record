# 第11章专题：建图系统与数据结构设计


## 学习目标

1. 建立关键帧-地图点双向关联的数据结构。
2. 学会在实时性与精度之间做建图策略权衡。
3. 设计可维护的前后端解耦架构。

## 核心概念

- 关键帧选择策略（视差阈值、时间阈值、信息增益）。
- 地图点生命周期（创建、融合、剔除、重观测）。
- 线程模型（前端跟踪、后端优化、回环检测、建图维护）。

## 与代码的映射模板

推荐模块划分：
- `frontend/`：跟踪与关键帧管理。
- `backend/`：优化与状态更新。
- `map/`：Frame、MapPoint、Map 容器。
- `io/`：配置、日志、可视化。

## 实践任务

1. 先定义 `Frame` 与 `MapPoint` 的最小字段集合。
2. 为地图点增加观测计数与质量评分，做稳定性筛选。
3. 补充线程安全策略（读写锁、原子计数、任务队列）。
